# Codex Monitor 0.1.4

* 打开活动会话即检查对应服务器，确认后才显示连接按钮；检查期间显示紧凑进度，找不到时直接给出原因。缓存结果、取消旧选择的检查，避免反复扫描和迟到结果覆盖。
* 校正 CLI 连接说明：共享后台服务器和 `--remote` 可以连接，不再笼统声称所有独立 CLI 无法连接。按实际服务器运行时归属判断。
* 新会话加入或删除时保留列表阅读位置、选中项和条目，不再重播整个列表的过渡。
* 移除左下角“本地文件”和本地状态说明。
* 推理摘要在活动组中直接显示，工具与事件保持单行折叠。
* 按 OpenAI 文档扩展计划、命令动作、网页、MCP、自定义工具、代理协作、图像、审查、上下文压缩及常见运行事件。进度事件更新原条目，最终结果替换流式草稿。
* 展开区改为本地化字段、计划步骤与状态、命令/输出和文件差异，已适配内容不直接显示 JSON。未知类型保留数据入口。
* 同步 22 种语言；增加结构化详情、异步预检、列表滚动锚点和流式事件回归。
* 保留嵌套工具列表与长输出的阅读位置、展开状态和键盘焦点；回看时暂停跟随，停在底部时自然接续新调用。
* 全面核对图标语义，为九种缺口生成主题适配图标，清理透明背景噪点并导出七档 DPI 资源。
* 补齐 UIA 名称、帮助、标题层级、展开模式、通知与焦点返回；对比主题使用不透明系统背景。87 项 UI MSTest 全部通过，含微软 Axe.Windows 扫描和 225% 字号压力布局验证。人工辅助技术验证边界见无障碍记录。

安装 `CodexMonitor-0.1.4-win-x64.msi` 可升级已有版本并保留设置。
