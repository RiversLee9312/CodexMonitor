# Codex Monitor 0.1.1

支持自动发现本机应用服务器和 Codex 主目录，并补齐未安装 CLI 时的引导。

* 切换到该选项时自动扫描，发现结果可直接选择，也可重扫或手动输入地址。
* 支持已运行的本地 Codex 守护进程控制套接字，以及 Codex 进程的 IPv4/IPv6 WebSocket 监听端口。
* 使用只读初始化握手确认服务；扫描不会创建、恢复或干预会话，也不会启动守护进程。
* 扫描可取消，关闭设置即停止；扫描过程中输入的手动地址会保留。
* 已发现但需要令牌的服务器会显示身份验证提示，暂不提供连接。
* 补全全部 22 种语言，并检查窄窗口、深浅色和 RTL 的发现界面。
* 设置自动查找环境变量、已配置及默认 Codex 主目录，支持多个结果、重新查找与手动浏览；保留有效路径及正在输入的内容。
* 未安装 CLI 时可继续阅读本地记录，欢迎页与连接操作提供官方安装入口、选择可执行文件及重新检查；连接现有服务器无需 CLI。
* 主目录尚未创建时显示空状态，设置仍可保存；仅在启动本地服务器时创建目录。

默认本地守护进程地址为 `unix://`，控制套接字取自设置中的 Codex 主目录。仅用 stdio、未开放共享监听的进程不能被发现。

安装 `CodexMonitor-0.1.1-win-x64.msi` 可升级已有版本；保留现有设置。
