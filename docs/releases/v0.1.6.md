# Codex Monitor 0.1.6

* 按 OpenAI Docs 和本机 CLI schema 全面核对 85 种通知、19 种原生条目、18 种持久化响应类型，加入可重复执行的协议清单检查。
* 本地与 app-server 复用条目适配器。修复服务器 sleep、动态/MCP 等待、内部完成事件、协作和子代理事件的用途、图标及状态。
* 区分 SDK 助手回复与代理间 agent_message；展开显示发送方、接收方及明文，忽略加密块。支持旧版事件和 SDK JSONL 的消息与工具生命周期。
* 细化 MCP 进度、补丁更新、终端输入、身份恢复、自动审批审查、实时文本及中断状态。修复多轮实时文本覆盖与本地镜像重复显示；完成项取代草稿，迟到进度不复活工具。
* 服务级通知收在详情的“服务器状态”。继续使用紧凑原生详情，保留未知类型的只读原文入口；新增文案覆盖全部 22 种语言。
* 扩展协议、连接/断联、窄屏深浅色、RTL、嵌套滚动和无障碍回归。保留 NativeAOT 自包含发布及 MSI 升级设置。

安装 `CodexMonitor-0.1.6-win-x64.msi` 可升级已有版本。完整范围与交互边界见协议覆盖文档；校验结果见随包 SHA-256 和 verification.json。
