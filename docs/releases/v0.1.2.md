# Codex Monitor 0.1.2

会话现在有独立的“连接”入口，工具活动改为逐行折叠。

* 点击会话页“连接”后，按服务器实际加载的会话匹配运行时。仅在历史列表中存在的记录不会被当作正在承载的会话。
* 加入已确认的运行时后才启用发送或引导。当前轮次尚不可用时保持只读并可重试；查找过程不启动、恢复或干预会话。
* 移除左下角全局连接按钮；断开连接移入会话菜单，新建与恢复历史会话按需连接。
* 推理摘要和工具调用合并为活动区。每次操作一行，可单独展开；文件编辑显示文件名与增删行数，命令显示摘要、状态和已有耗时。
* 参数、输出和差异按需展开并分别复制；展开状态在更新时保留。长活动列表使用虚拟化。
* 22 种语言同步更新，并检查窄窗口、深浅色及 RTL 布局。

独立的 `codex exec` 或仅用 stdio 的进程没有共享监听，无法通过连接另一个 app-server 来接管。此时保留本地阅读并明确提示；不会启动第二个运行时来冒充连接成功。

安装 `CodexMonitor-0.1.2-win-x64.msi` 可升级已有版本并保留设置。
