# Codex Monitor 0.1.0

首个 Windows x64 版本，提供原生 WinUI 3 的 Codex CLI 会话查看与轻量控制。

* 查看本地、归档、子代理会话，搜索、复制和导出对话。
* 连接 app-server 后发送消息、引导当前回合和停止运行，支持命令与文件修改审批。
* 内容更新保持列表条目和位置，仅显示主题色未读点；新增或删除会话才使用列表过渡。
* 服务器确认活动的会话显示运行中标识，断线后移除。
* Fluent 深色/浅色、响应式侧栏、22 种语言与 RTL 支持。
* 修复深浅主题切换后原生窗口控制按钮未同步的问题。

安装 `CodexMonitor-0.1.0-win-x64.msi`。安装在当前用户的 `%LOCALAPPDATA%\Programs\CodexMonitor`，开始菜单搜索 Codex Monitor 即可打开。卸载使用 Windows“已安装的应用”。包含所需运行时；连接功能另需已安装并登录的 Codex CLI。

steer 需要连接承载目标会话的同一 app-server。普通独立 CLI 会话可以阅读，不会因为读取日志而被直接接管。

验证：34 项核心及发布 MSTest（含已安装 CLI 的只读集成和发布程序启动）和 19 项 WinUI UI 测试通过，并检查深浅色、不同窗口尺寸与 RTL 截图。
