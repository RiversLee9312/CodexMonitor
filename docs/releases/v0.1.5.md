# Codex Monitor 0.1.5

* 对话采用单一数据来源：未连接时读取本地 transcript，连接该会话后只使用 app-server。文件变化不再覆盖服务器事件；主动与意外断联后重新读取本地记录，过期读取和旧连接回调受到隔离。加测断开后的来源切换与重新连接。
* 按协议字段区分推理摘要和明文思考：摘要完整展示，明文思考默认折叠，加密内容始终忽略。新增思考图标，清理透明噪点并导出七档 DPI 资源。
* “转到最新内容”改为圆形向下悬浮按钮，离开底部显示、到底部隐藏，不挤占阅读区。快速淡入淡出与位移遵循系统动画偏好。
* 设置新增开源许可证页，展示依赖版本、许可原文与第三方声明。返回保留未保存的设置，原文在 RTL 界面中保持正确方向。同步 22 种语言、242 个资源键。
* Release 改用 NativeAOT 和按需 Windows App SDK 组件包；MSI 从约 71.9 MiB 缩小到 22.2 MiB，约减少 69%。保留全部语言、主题和自包含运行能力。
* 补充真实发布程序启动检查、许可证无障碍扫描、思考折叠、悬浮按钮、历史/流式通知交错和连接生命周期回归。验证边界见无障碍与界面记录。

安装 `CodexMonitor-0.1.5-win-x64.msi` 可升级已有版本并保留设置。完整校验见随包的 SHA-256 与 verification.json。
