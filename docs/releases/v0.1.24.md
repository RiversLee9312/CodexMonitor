修复 ItemsRepeater 列表在会话更新时丢失阅读位置的问题。

- 连续更新保留同一个阅读锚点；工具输出和推理摘要变长时也保持位置。
- 工作过程被虚拟化回收后，按具体工作记录及其屏内位置恢复阅读，不再只使用旧的像素偏移。
- 本地文件重新读取期间，已有界面的滚动操作继续有效；切换会话或数据源时仍会取消过期操作。
- 工具内容更新后的焦点维护不会触发自动跳转；新的鼠标或键盘操作优先于延迟的位置还原。
- 展开的工具输出连续重建时保留原来的阅读位置；新增进度或标准输入区域不再干扰输出区域的位置。
- 会话列表重排时避免对仍在视口中的锚点执行额外跳转。

MSTest 回归覆盖本地文件与 app-server 的会话列表、对话内容和工作过程，包含实际文件追加、服务器通知、断联后切回本地、快速滚轮输入、内容增高、连续更新、删除锚点及屏外回收。

本机最终验证：207 项 UI 功能测试、1 项独立导航性能基准及 255 项 Core 测试通过。另有原生发布启动检查由 CI 构建后执行。

MSI 为自包含 NativeAOT x64 版本，由 GitHub Actions 在 Core 测试及原生启动检查通过后构建发布。
