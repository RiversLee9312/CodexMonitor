# Codex Monitor 0.1.8

* 包含0.1.7的命令数组、镜像去重、旧版事件标题和主题切换阅读位置修复。
* 修复首次连接服务器并批量加入会话时的侧栏跳动。保存可见行的位置，批次更新后恢复；后续用户滚动或切换会话时取消过期恢复。新增一次导入200个会话的真实 WinUI 回归。

* 新增解析变体、误识别、资源限制、两种来源一致性以及浅色/深色/RTL窄窗口回归。Acornima 的原始许可证与NOTICE加入开源许可证页面。
* 按 OpenAI App Server 文档使用 excludeTurns:true 订阅会话，然后通过分页方法读取历史，避免旧参数引起完整历史加载和弃用警告。
* 补做安装版的原生深浅标题栏、常规和最大化布局、真实工具详情与滚动、服务器连接及断开后的来源切换检查。保留所有语言、主题与 NativeAOT 发布。
