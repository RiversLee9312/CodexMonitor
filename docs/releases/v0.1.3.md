# Codex Monitor 0.1.3

会话底部按连接状态切换，并为等待活动提供专用展示。

* 未连接时，底部只提供适用的一项操作：未加载的历史会话可“恢复会话”；活动中、已加载或状态未确认的会话显示“连接应用服务器”。说明文案解释该操作能完成什么。
* 恢复前重新检查日志与服务器状态，发现会话已活动时转为连接，避免重复恢复运行时。
* 连接成功后隐藏操作说明与入口，显示输入框与发送按钮。原“连接此会话后即可发送消息”提示移除。
* 无法连接时，用感叹号和原因原位替换连接按钮及其说明；移除连接失败横幅。可在会话菜单重新检查。
* 等待调用显示时钟、设定时长与完成状态；真实运行时的等待显示动画，历史记录保持静态。原始参数和输出留在详情中。
* 移除“显示工具活动”复选框；活动直接以紧凑折叠行展示，逐项展开查看。
* 同步全部 22 种语言，并验证窄窗口、深浅主题、德语与 RTL 的底部布局和等待状态。

安装 `CodexMonitor-0.1.3-win-x64.msi` 可升级已有版本并保留设置。
