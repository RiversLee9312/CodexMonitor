## 已修复的问题

* 高 DPI：初始窗口尺寸以 XamlRoot.RasterizationScale 换算，且限制在当前显示器工作区内。
* 覆盖侧栏：透明背景导致正文透出，改为主题适配的不透明原生背景，并启用 light-dismiss 遮罩。
* 标题栏：在 RequestedTheme 改变后立即读取 ActualTheme 会读取到旧主题。改为监听 ActualThemeChanged，同步 AppWindowTitleBar.PreferredTheme，交由系统处理按钮颜色、悬停、按下和非激活状态。
* 对话密度：工具调用与返回合并为一条活动，默认隐藏，展开时保留内容。
* 标题缺失：无索引标题时从用户消息补全，并保留省略号及完整标题 tooltip。
* 辅助功能：消息列表项用角色、时间和内容摘要作为可读名称。

## 验证边界

布局断言与截图不是像素基准比对，也不是无障碍认证。尚未独立运行 Narrator 全流程、200% 系统文字缩放、Windows 高对比主题、Windows 10 或 ARM64 真机验证。核心和发布层 59 项 MSTest（含已安装 CLI 的只读集成测试和实际发布程序启动检查）另行通过；没有对真实用户会话发送测试指令。

发布检查另发现并修复 WinUI PRI/XBF 没有进入发布目录的问题。项目明确列入所需资源，Publish 与 MSI 构建检查其存在，MSTest 直接运行发布后的可执行文件，防止只在开发输出目录验证成功。

Debug 版本提供 Ctrl+Alt+1/2/3/4 尺寸切换，5/6 深浅主题，7/8/9 阿拉伯语/德语/简体中文。它们不进入 Release 构建，也不保存设置。
